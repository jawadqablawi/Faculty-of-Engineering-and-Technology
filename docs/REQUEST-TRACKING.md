# اختبار لوحة تتبّع الطلب

استخدم حسابات وطلبات تجريبية. كرّر الفحص بعرض جوال 360 بكسل، وعلى الكمبيوتر، وفي الوضع الداكن ومع تفعيل تقليل الحركة.

| الحالة | النتيجة المتوقعة |
|---|---|
| مسودة جديدة بلا سجل انتقالات | التقديم هو المرحلة الحالية. |
| إرسال طلب أو إعادة إرساله | المراجعة هي المرحلة الحالية، ومدتها تبدأ من آخر إرسال. |
| طلب تعديل | تظهر المراجعة بحالة تحتاج إجراء، وزر التعديل متاح للنادي، والسبب ظاهر لمن يحق له قراءته. |
| رفض أو إلغاء | تُعرض الحالة النهائية، ويظهر موضع التوقف عند وجود انتقال موثّق. |
| موافقة أولية في المسار القديم | تظهر الموافقة الأولية، ويشار إلى تجهيز الكتاب قبل الإحالة. |
| لدى المجلس | المرحلة الحالية هي المجلس. بعد الموافقة يظهر تاريخها إن وُثق ومن سجّلها. |
| لدى شؤون الطلبة أو الجامعة | يُعرض مسار الطلب الفعلي والجهة التالية. افحص جهة إلزامية وأخرى اختيارية. |
| معتمد ثم مكتمل | يظهر الاعتماد، ثم الإغلاق بعد التقرير حسب مسار النظام. |
| طلبات واردة أو طلباتي | تظهر المرحلة بجانب شارة الحالة. |

تحقق أن اللوحة والأزرار تسبق التفاصيل عند المراجعة. افتح «عرض تفاصيل الطلب»، ثم «فتح العرض الكامل للطلب» للتحقق من التفاصيل وسجل النسخ بحسب صلاحية الحساب. جرّب فتح رابط الطلب من نادٍ آخر، والتحقق من اختفاء ملاحظات القرار عند استعمال حساب مراجع للقراءة فقط.
