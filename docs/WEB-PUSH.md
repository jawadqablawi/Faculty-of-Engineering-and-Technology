# إشعارات الجوال في ETCS

## 1. تثبيت التطبيق
افتح موقع ETCS عبر HTTPS. على أندرويد اختر تثبيت التطبيق من قائمة المتصفح. على iPhone أو iPad بنظام 16.4 أو أحدث افتح Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية، ثم افتح التطبيق من الأيقونة. لا يخزّن عامل الخدمة صفحات الحسابات أو محتواها للاستخدام دون اتصال.

## 2. إعداد المفاتيح
على جهاز إداري نفّذ:

```bash
npx --yes web-push@3.6.7 generate-vapid-keys --json
```

في Vercel ← مشروع ETCS ← Settings ← Environment Variables، أضف في **Production**:

| الاسم | القيمة |
|---|---|
| `VAPID_PUBLIC_KEY` | قيمة `publicKey` الناتجة |
| `VAPID_PRIVATE_KEY` | قيمة `privateKey` الناتجة، تحفظ سرًا |
| `VAPID_ADMIN_EMAIL` | بريد إداري حقيقي، بدون بادئة `mailto:` |
| `CRON_SECRET` | أبقِ السر المهيأ لمسار التذكيرات؛ إذا كان مفقودًا اضبط سرًا عشوائيًا مستقلًا |

انشر الكود مع إعدادات البيئة. أمر بناء Vercel الحالي يطبّق هجرة الاشتراكات تلقائيًا. من **الإشعارات ← إعدادات إشعارات الجوال** اضغط زر التفعيل ووافق على إذن المتصفح. يمكنك تغيير الفئات أو إزالة جهاز لاحقًا. احتفظ بالمفاتيح عند إعادة النشر؛ إذا دوّرتها فعلى الأجهزة إلغاء الاشتراك القديم من المتصفح وإعادة الاشتراك.

## 3. التشغيل وإعادة المحاولة
يستمر الإشعار داخل الموقع في العمل مع المفاتيح وبدونها. عند وجود المفاتيح، يسجّل النظام مهمة تسليم ويحاول الإرسال بعد نجاح معاملة قاعدة البيانات. يفتح الإشعار المرتبط بطلب صفحة ذلك الطلب. تعمل الإرسالات الفورية مع التطبيق المفتوح أو المغلق وفق إذن الجهاز وسياسات المتصفح.

يشغّل Vercel Cron الحالي `/cron/reminders/` يوميًا عند 06:00 UTC، ويحاول إرسال التذكيرات والمهام المستحقة. موعد إعادة المحاولة يعتمد على موعد تشغيل Cron التالي. يُسجّل النظام نتيجة مختصرة لكل جهاز ويزيل الاشتراك عند 404 أو 410. سجل التطبيق لا يتضمن مفاتيح الاشتراك أو عنوان الجهاز. منع إعادة الإرسال يعتمد على سجل التسليم ومعرف الإشعار، ويستخدم الهاتف وسمًا لتجميع تحديثات الطلب المتشابهة. قد يتكرر التسليم إذا قبل خادم الدفع الرسالة وتعطلت العملية قبل تسجيل النتيجة.

يدعم الخادم حاليًا نقاط الدفع المعروفة من Google وApple وMozilla وMicrosoft، مع حد خمسة أجهزة للحساب. لا تستخدم معاملات الاختبار أو بيانات المستخدمين الحقيقية في اختبارات التكامل.

## 4. قائمة الاختبار اليدوي

- [ ] أندرويد، تثبيت التطبيق، فتح إعدادات الإشعارات، التفعيل وإعادة فتح الصفحة لرؤية الحالة.
- [ ] iPhone أو iPad، ظهور إرشاد Safari قبل التثبيت، ثم التفعيل عبر أيقونة التطبيق المثبّت.
- [ ] إغلاق التطبيق وإرسال طلب تجريبي من حساب نادٍ. يتلقى المنسق والنائب أو المراجع المخوّل إشعارًا. يفتح الضغط صفحة الطلب بعد تسجيل الدخول إذا لزم.
- [ ] إعادة الطلب للتعديل ثم إعادة إرساله. يتلقى النادي نصًا عامًا ويستلم المشرف المخوّل إشعار إعادة الإرسال.
- [ ] رفض طلب تجريبي والتأكد من أن السبب لا يظهر على شاشة القفل. جرّب كذلك تسجيل كتاب رسمي وتذكير التقرير.
- [ ] تسجيل حساب نادٍ آخر على جهاز آخر، والتأكد من أنه لا يستلم طلب النادي الأول أو يستطيع إزالة جهازه.
- [ ] إيقاف فئة أو إزالة جهاز والتأكد من توقف وصولها، مع بقاء الإشعارات داخل الموقع.
- [ ] اختبار التذكيرات من Cron مع سر الاختبار، والتحقق من عدم تكرار التذكير نفسه في اليوم نفسه.
